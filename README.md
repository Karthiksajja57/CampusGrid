# CampusGrid 🎓

### Everything Campus. One Grid.

CampusGrid is a centralized web application designed to connect students and faculty through a unified platform for discovering and managing college opportunities, events, and announcements.

## 📌 Problem Statement

Information about internships, hackathons, workshops, technical events, and other academic or professional opportunities is often shared through WhatsApp groups and informal communication channels. This leads to scattered information, missed deadlines, difficulties in tracking registrations, and additional coordination efforts for faculty members.

CampusGrid aims to solve these problems by providing a centralized platform where faculty can publish opportunities and manage registrations, while students can discover opportunities, register for activities, and track their registration status.

## 🎯 Objectives

* Centralize college opportunities and announcements.
* Help students discover relevant academic and professional opportunities.
* Enable faculty to publish and manage opportunities.
* Simplify student registration and participation tracking.
* Improve deadline awareness and communication.
* Maintain organized records of student participation.

## ✨ Planned Features

### 👨‍🎓 Student Features

* Browse opportunities by category.
* View descriptions, eligibility criteria, and deadlines.
* Register for opportunities.
* Access external registration links when applicable.
* Track registration status and history.
* View announcements and upcoming deadlines.

### 👨‍🏫 Faculty Features

* Publish, update, and manage opportunities.
* Define registration deadlines and eligibility criteria.
* View registered students.
* Track participation records.
* Access an analytics dashboard.

### 📂 Opportunity Categories

* Internships
* Hackathons
* Events
* Other Opportunities

## 🏗️ Proposed Architecture

1. **Frontend:** React.js with Vite provides the user interface.
2. **Backend:** Spring Boot exposes REST APIs and implements application logic.
3. **Database:** MongoDB stores user profiles, opportunities, announcements, and registration records.
4. **Communication:** The frontend communicates with the backend through REST APIs.
